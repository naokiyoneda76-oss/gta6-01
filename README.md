An original open-world crime game that runs entirely in the browser, built for [make.fun](https://make.fun)'s "Make GTA 6" bounty.

Welcome to Palmera City, a golden-hour coastal city of six districts. Play as Danny Cole: run six story missions, jack cars, outrun the police under the HEAT wanted system, take taxi fares, race checkpoints and hunt down eight postcards — all in one seamless open world with traffic, pedestrians who react, a full map and minimap, and a synthesized soundtrack. No downloads, no server: it plays offline from static files.

## Run it

Open `game/index.html` in a desktop browser, or serve the folder:

```
cd game && python3 -m http.server 8080
```

then visit http://localhost:8080.

## Controls

- WASD / arrows — move / drive
- E — enter / exit car, talk, interact
- SPACE — handbrake / action
- SHIFT — dash
- Mouse — aim, click to shoot
- Tab — full map, ESC — pause

Progress saves automatically to localStorage.
